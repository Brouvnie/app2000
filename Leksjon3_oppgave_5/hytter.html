Hytter:

Svar på spørsmål:

En mulig JSON-representasjon av hyttedata kan inneholde informasjon om navn, lokasjon, hyttetype, pris, fasiliteter og antall sengeplasser. Lokasjon kan representeres som et underobjekt, mens fasiliteter kan representeres som et array.

Eksempel:

[
            {
                "id": 1,
                "name": "Fjellheim",
                "location": {
                "municipality": "Lom",
                "latitude": 61.837,
                "longitude": 8.568
                },
                "type": "Betjent",
                "pricePerNight": 650,
                "facilities": ["Dusj", "WiFi", "Restaurant"],
                "beds": 40
            }
            ]

I TypeScript kan man lage interfaces som beskriver hvordan dataene skal være bygget opp. Dette gjør det mulig å angi hvilke datatyper de ulike egenskapene skal ha. 

interface CabinLocation {
            municipality: string;
            latitude: number;
            longitude: number;
            }

            interface Cabin {
            id: number;
            name: string;
            location: CabinLocation;
            type: string;
            pricePerNight: number;
            facilities: string[];
            beds: number;
            }

Deretter kan hyttene vises ved hjelp av en funksjon som går gjennom arrayet og oppretter HTML-elementer: 

function displayCabins(cabins: Cabin[]): void {
                const container = document.getElementById("cabins");

                if (!container) {
                    return;
                }

     for (const cabin of cabins) {
    const cabinElement = document.createElement("div");
    cabinElement.className = "cabin";

        cabinElement.innerHTML = `
      <h2>${cabin.name}</h2>
      <p>Sted: ${cabin.location.municipality}</p>
      <p>Type: ${cabin.type}</p>
      <p>Pris per natt: ${cabin.pricePerNight} kr</p>
      <p>Sengeplasser: ${cabin.beds}</p>
      <p>Fasiliteter: ${cabin.facilities.join(", ")}</p>
        `;

        container.appendChild(cabinElement);
         }
        }

En fordel med TypeScript sammenlignet med JavaScript er at TypeScript støtter statisk typing. Dette gjør at feil, for eksempel at antall sengeplasser blir lagret som tekst i stedet for et tall, kan oppdages allerede ved kompilering. Interfaces gjør også datastrukturen tydeligere og kan gjøre koden lettere å vedlikeholde. TypeScript gir i tillegg bedre støtte for blant annet autoutfylling og feilmeldinger i utviklingsmiljøet.

En ulempe er at TypeScript krever et ekstra steg fordi koden må kompileres til JavaScript før den kan kjøres i nettleseren. Det innebærer også litt mer kode og oppsett enn ved bruk av vanlig JavaScript.

Koden kan testes ved å kompilere TypeScript-filen til JavaScript og deretter åpne HTML-siden i en nettleser. Man kan kontrollere at alle hyttene blir vist med riktig informasjon. TypeScript-kompilatoren kan også testes ved å legge inn en verdi med feil datatype, for eksempel beds: "40", og kontrollere at kompilatoren gir en feilmelding.
